# MES 및 제품 탄소 데이터 서비스 제품 기획

개발보다 제품 기획을 먼저 정리한 검토본이다. 제조 운영과 탄소 산정을 별도 책임 영역으로 설계하고, 두 영역이 공유하는 데이터·정정·승인 계약으로 연결한다. 이 폴더에는 제품 코드나 실행 가능한 구현이 없다.

- 기준일: 2026-11-03
- 버전: 1.0
- 상태: **기획 검토본**
- 기본 방향: 선택 제조단계의 gate-to-gate 부분 탄소산정에서 시작한다. Cradle-to-gate는 상류 증빙과 고객 범위 합의 후 조건부 확장한다.
- 고객·산업·가격·SLO·일정·성과: **제안 또는 미검증 가설**이다. 기존 고객 데이터, 상용 실적, 인증, 외부 검증 완료를 주장하지 않는다.

## 핵심 제품 결정

1. 첫 MVP는 선택한 제조단계의 부분 탄소산정이다. 이를 전체 제품 PCF 또는 다영향 LCA로 부르지 않는다.
2. 경량 MES와 기존 MES 읽기 연계는 고객별 진입 경로다. 같은 생산 사실을 두 시스템에서 동시에 확정하지 않는다.
3. 계획 BOM, 실제 소비, 구매량은 다르다. 초회 양품, 공정 통과량, 최종 양품, 출하량도 다르다.
4. 원 계량값과 제품별 배분값은 따로 관리한다. 상위·하위 미터, 공급사 PCF·원재료 upstream을 중복 합산하지 않는다.
5. 정정은 새 사건과 버전으로 표현한다. 승인 스냅샷·계산 Run·과거 공유본을 조용히 덮어쓰지 않는다.
6. MES 마감, 탄소 검토 승인, 외부 공유 승인은 서로 다른 권한과 상태다.
7. 온톨로지와 KG는 의미·추적성에 먼저 사용한다. GNN은 충분한 데이터와 단순 대안 대비 가치가 검증될 때만 도입한다.
8. 설비 제어, 범용 ERP·MES 전면 교체, 전사 ESG·자동 EPD·인증·규제 자동 준수는 초기 약속이 아니다.

## 공통 수치 예시

모든 값과 계수는 가상 계산 검증용이다. 실제 업체·공식 전력계수·검증된 PCF가 아니다.

- 실제 원료 115 kg = 양품 100개 × 0.8 kg + 스크랩 35 kg.
- 초회 양품 90개 + 재작업 회복 10개 = 최종 100개. 110개로 중복 집계하지 않는다.
- 전력 1000 kWh = 제품 A 660 + 제품 B 330 + 다른 제품 C 전용 공정 10. 단순한 기타 공용부하라면 추가 귀속 검토가 필요하다.
- 선택 제조단계 예시: 660 × 0.5 = 330 kgCO2e, 100개 기준 3.300 kgCO2e/개.
- 추가 경계·증빙을 가정한 cradle-to-gate 확장: 563.85 kgCO2e, 100개 기준 5.6385 kgCO2e/개.
- 두 결과는 범위가 다르다. 서로 비교해 감축률을 계산하지 않는다. 상세 조건과 민감도는 [탄소 방법](03-carbon-methodology.md)에 있다.

## 문서의 상태와 변경 원칙

**사용자 방향**은 기획 우선과 초기 제조단계 범위다. **제안**은 산업·화면·정책·가격·운영 목표다. **미검증**은 실제 고객 데이터·구매·성능·복구·인증과 관련된 주장이다. **출시 기준**은 앞으로 증거로 통과해야 하는 조건이다. 이 구분을 변경 이력에서 유지한다.

- 공통 필드·정정·권한·보존 정책은 [02](02-data-contract-and-security.md)를 기준으로 수정한다.
- 산정 정책·예시는 [03](03-carbon-methodology.md)를 기준으로 수정한다. 숫자를 바꾸면 01의 시나리오와 05의 예상값도 확인한다.
- 기능·서비스 목표·가격·출시 테스트는 [05](05-launch-and-commercial.md)를 기준으로 수정한다.
- 도메인 책임 역할은 제안이며 실제 사람 배정은 미정이다. TODO의 체크는 증거가 있을 때만 한다.
- 보안·보존·데이터 라이선스·표준 버전은 실제 계약과 출시 시점에 다시 확인한다.
- 공식 출처는 관련 문장 옆과 각 문서의 자료 목록에 있다. 유료 ISO 전문의 조항별 적합성 검토는 수행하지 않았다.
